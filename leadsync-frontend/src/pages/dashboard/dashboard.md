# Dashboard Pages

## Overview

Contains sub-features for the internal dashboard of LeadSync.

## Modules

- `agent-inbox/`: Complete real-time chat interface for agents interacting with clients.
- `agent-task-card/`: Tasks specifically assigned to support agents.
- `broadcasts/`: Mass messaging tools.
- `conversations/`: History of past chats.
- `dashboard-home/`: Landing view post-login showing top metrics.
- `leads/` & `orders/`: Domain-Specific views.
- `settings/` & `user-management/`: Admin configuration tools.
