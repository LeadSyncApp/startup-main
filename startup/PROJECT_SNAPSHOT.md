# PROJECT SNAPSHOT

## Project
LeadSync CRM

## Stack
- Frontend: React (Vite) → Vercel
- Backend: Node.js + Express → Railway
- DB: PostgreSQL (Supabase) + Prisma

## Architecture
- Monolithic backend (moving → microservices)
- REST APIs
- Multi-tenant (company-based)

## Core Modules
- Auth
- Leads
- Conversations
- Orders
- Automation
- Integrations (Telegram, Instagram)
